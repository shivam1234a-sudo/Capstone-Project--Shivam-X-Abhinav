# 📚 Capstone Project – Shivam X Abhinav

A simple and responsive **Book Search Web App** built using **HTML, CSS, and JavaScript** that fetches real-time book data using the Google Books API.

---

## 🚀 Features

✅ Search books by title, author, or keyword
✅ Display book cover images
✅ Show author names and titles
✅ Sort books A → Z
✅ Sort books Z → A
✅ Responsive design
✅ Default books shown on page load

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Google Books API
